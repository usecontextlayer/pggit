# Breakage conversion mapping — lens `pg-corrupt`

> **Point-in-time conversion record (2026-08-15).** Verdicts and mechanism names below describe the code as converted, not the landed derived-state spine or later review fixes. This file is deliberately not updated; read it as frozen provenance for the conversion.

7 source scripts assigned, 7 converted. Every one routed to **e2e**: each verdict is a
correctness property (byte-identity, an invariant over the derived tier, a specific
HTTP failure mode, a match against a real-git oracle) and each builds its own repo
hermetically — no measured threshold owns a script's exit code, and none needs an
external checkout. `perf/breakage/` therefore holds only this mapping.

## Notes

- **No helper file was converted.** None of the 7 assigned scripts imports `breakage/_lib.ts`,
  `_pgres.ts`, `_bloatlib.ts`, `_perf-util.ts` or any other `_`-prefixed module — every one
  imports only `@/…` production and `src/testing/` helpers. The script-local helpers
  (`mk`, `fail`, `firstDiff`, `mineOid`, `refLines`, `createRefStdin`, `buildSource`,
  `cloneBytes`, …) are inlined into each destination test, per the house style.
- **Postgres**: every `postgres://…:6489` literal was replaced by
  `createIsolatedSchema(inject("pgBaseUrl"))` with `drop()` in `afterAll`. The
  cross-schema-bleed test deliberately carves TWO schemas out of that one base URL —
  sharing the container's database is the property under test. The delta-must-win test
  carves two as well (a repacked SUBJECT and an un-repacked BASELINE) for its pack-size
  comparison.
- **Scale preserved verbatim**: 64/190 MB blobs, 100 000-entry trees × 6 versions,
  40 pathological versions, 80-version lineage, 50 MB random blob, 16 mined OIDs,
  3 000-commit history, 4 000 unrelated tips, 45 steps × 2 sides × 2 rounds. Large
  fixtures are built with `git fast-import` where the source did.
- **Real-git oracles preserved**: the `file://` bare reftable remote (refname),
  `git ls-tree -r -z` (path collision), `git fsck --full --strict --no-dangling` and
  `count-objects -v` size-pack (everywhere a clone is taken).
