## Routing note — the one e2e

`perf--repack-small-object-wall.ts` is the lens's exception. Its FAIL CONDITION is purely a correctness property ("repack() throws on a repo `git repack -adf` handles fine") with no measured threshold anywhere, and it builds its fixture hermetically via `git fast-import`, so the spec routes it to `src/e2e/breakage/`. `perf--deep-nesting.ts` looks similar but its exit is `crashed || worstRatio > 20`, a ratio threshold, so it stayed perf with the crash and `fsck --strict` checks preserved inside the one destination.

## Deliberate adaptations

- **`--pg=` flag.** The spec's perf-harness rule asks for it. `PG_URL` in `_perf-util.ts` now resolves through `flag("pg", "postgres://postgres:postgres@localhost:6489/postgres")`, so every harness picks it up unchanged. Ad-hoc `process.argv.find(...).slice(n)` readers in the sources were replaced by the same `flag()` for consistency with `perf/delta-probe.ts`; defaults are byte-identical to the originals.
- **`main().catch(...)` shape.** Sources used a top-level `try { await main() } finally { cleanupTmp() }`. Converted to `main().catch((err) => { console.error(err); process.exitCode = 1 }).finally(cleanupTmp)` to match `perf/delta-probe.ts`, keeping the same cleanup.
- **`perf--repack-memory.ts` self-spawn.** `SELF` now points at `perf/breakage/perf--repack-memory.ts`, and the parent's resolved `PG_URL` is forwarded to the child as `--pg=` so both halves reach the same server when a non-default `--pg` is passed. Still run it from the repo root.
- **e2e helper inlining.** Per the spec, the e2e test inlines its own `importRepo` / `gitRepack` / `reachableObjects` / `seedRepo` rather than importing `_perf-util`. `gitRepack` there drops the `/usr/bin/time -l` peak-RSS wrapper (no RSS assertion in that test) and uses `spawnGit`, whose non-zero-exit rejection IS the "git handles it fine" oracle. `reachableObjects` keeps its single `git cat-file --batch` — a per-object spawn over 100 000 objects is exactly the anti-pattern the spec forbids.
- **Postgres in the e2e.** `createIsolatedSchema(inject("pgBaseUrl"))` with `drop()` in `afterAll`; no `:6489` anywhere in `src/`.
