# Conversion mapping — lens `txn` (crash integrity)

> **Point-in-time conversion record (2026-08-15).** Verdicts and mechanism names below (`sweepEncodings`, `gc_live_<id>`, `deletedEncodings`, …) describe the code AS CONVERTED; the 2026-08-16 defect-fix pass redesigned several of them (delta-pack doc D11–D16). This file is deliberately NOT updated — read it as the frozen record of what each harness asserted at conversion time.

Seven source scripts assigned, seven converted. One source script → exactly one destination artifact; no script split, none dropped. Routing is by each script's PRIMARY exit verdict: a measured threshold (bytes / ms) goes to a perf harness, a correctness or convergence property goes to a vitest e2e test. Secondary checks stay inside the one destination they belong to.

`pg-txn--*` scripts are a DIFFERENT lens and are untouched by this conversion.

## Conversion notes

- Every e2e destination replaces the source's hardcoded `postgres://…:6489` with `createIsolatedSchema(inject("pgBaseUrl"))` and drops the schema afterwards. Scripts that used several pristine schemas (one per kill point / scenario / trial) keep that shape via a local `withSchema` helper — each schema is created and dropped inside the loop, so no destination holds more than one open at a time.
- Assertions encode CORRECT behavior, so a reproduced bug is a RED test. The source scripts printed the defect and exited 0; the tests assert the value the defect makes wrong (`expect(torn.orphaned).toBe(0)`, `expect(divergentRows).toBe(0)`).
- Fixture scale is preserved exactly: 400 runs for the interrupted-repack pair, 300 for the sweep window, 150 for the two races and the holes probe, 50 (with `KEEP_AT = 45`) for the torn GC. The 5-trial probabilistic loop and the three kill points are preserved as loops, not collapsed.
- The real-git oracle is preserved everywhere it appeared: mirror clone + `git fsck --strict --no-dangling`, and the client-side pack-byte measurement via `packFiles` / `PACK_DIR`.
- `perf/breakage/txn--gc-sweep-window.ts` and `src/e2e/breakage/txn--torn-gc-wedges-repack.test.ts` are the two halves of one finding (how wide the crash window is, and what a crash inside it leaves behind); each header points at the other. The same pairing holds for `txn--interrupted-repack.test.ts` (the I6 divergence) and `perf/breakage/txn--interrupted-repack-cost.ts` (what that divergence costs).
