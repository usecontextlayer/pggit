# Lens `race` — breakage script → house-pattern mapping

11 source scripts assigned, 11 converted. Every one routed to **e2e** (`src/e2e/breakage/race--<name>.test.ts`): each builds its own fixture hermetically (`createAppendOnlyRepo` + `git fast-import`) and its exit verdict is a correctness property — a clone/fetch/push succeeding or failing cleanly, `git fsck --strict`, an object-set identity, a "GC must delete zero reachable objects" invariant, or a specific error mode / HTTP status. No script in this lens measures a threshold or needs an external repo, so `perf/breakage/` holds only this mapping.

None of the 11 imports a `breakage/_*.ts` helper — each carries its own copy of the one-`cat-file --batch` `loadObjects()` reader, which is inlined into the destination test (house style). Where the script hand-rolled an OID lister, the destination reuses `allObjectOids` from `@/testing/git-fixtures`; the hardcoded `postgres://…:6489` is replaced everywhere by `createIsolatedSchema(inject("pgBaseUrl"))` + `drop()` in `afterAll`. Iteration counts, mode sweeps, delay tables and fixture sizes are frozen at the scripts' defaults — these are probabilistic races, so the loop IS the test.

## Notes

- **Nothing was split or dropped.** Where a script had multiple parts with independent verdicts (`race--clone-vs-gc-rewind`'s real-git oracle, `race--err-pkt-overflow`'s deterministic Part 1 vs raced Part 2), the parts became separate `it` blocks inside the ONE destination file. Where a script swept modes inside a shared loop (`clone-vs-repack`, `deleterepo`, `two-pushes-repack`), the nested loop is kept verbatim inside one `it` so the break-on-first-reproduction ordering is preserved.
- **Every script's "exit 1 when reproduced" became an assertion of the CORRECT outcome**, so the ones with live bugs are red today. Breaks are accumulated into a `breaks: string[]` and asserted with `expect(breaks).toEqual([])`; per-round diagnostics (timings, verdict tallies, chain depth) ride on `expect`'s message argument so they print only on failure.
- **Timeouts**: `beforeAll` 600_000–900_000 ms (fixture build + container schema), tests 900_000–3_600_000 ms depending on iteration count × fixture size (`race--clone-vs-repack` is the heavy one: 90 raced clones of a 1200-run repo).
- **No utility/helper scripts** were in this lens's assignment, and no assigned script imported one.
